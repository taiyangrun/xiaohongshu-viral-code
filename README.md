# 小红书流量密码 (`xiaohongshu-viral-code`) v1.0.1

基于千级爆款样本研究的小红书流量密码：一键诊断文案（标题/正文/标签/封面/发布时间）并改写，给视频内容提供修改建议，附17式标题公式库、流量词库与发帖检查清单。Pro版（含一键全案JSON、爆款拆解、选题引擎、数据医生，0.33元/次）：xiaohongshu-viral-code-pro

Diagnose and rewrite Xiaohongshu (RED) post copy and give video revision suggestions based on viral-content research across 1000+ sampled posts and videos. Use when the user wants to improve a Xiaohongshu title, body text, tags, cover, or posting time, needs title formula options, a traffic-word bank, a pre-post checklist, or actionable revision advice for a short video (hook, duration, structure, comments).

## 文件结构

- `SKILL.md` —— skill 定义（含完整转绘提示词配方 / 工作流）
- `agents/openai.yaml` —— agent 配置
- `icon.png` —— skill 定制图标

## 使用方式

将本仓库作为 skill 包使用：把 `SKILL.md`、`agents/`、`icon.png` 放入你的 skill 目录即可。也已同步上架 [skillhub.cn](https://skillhub.cn) 与 ModelScope（魔搭社区），搜 `xiaohongshu-viral-code` 即可找到。
